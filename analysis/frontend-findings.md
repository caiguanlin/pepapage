## 3. 制作同步阅读项目

证据 J@3003400–3043700，可检索 `制作项目`、`带字幕视频，使用外部 SRT 字幕`。

| 类型 | 输入与处理 | 差异 |
|---|---|---|
| 音频 / 仅 PDF | PDF、音频，可走 PDF-only | 书页文字与语音字幕映射 |
| 视频 | 视频文件，可多选 | 按文件名批量创建，生成字幕并抽帧合成 PDF |
| 链接 | 视频 URL 或 `ydl://` 下载码 | 下载后创建；UI 提及 YouTube / TED 等 yt-dlp 支持站点 |
| 投屏 | 同 WiFi 手机投屏到接收端 | 接收完视频再探测时长和识别计费 |
| 带字幕视频 | 视频 + SRT | 跳过语音识别，信任外部字幕，不消耗识别积分 |
| 仅音频 | 音频 | 跳过 OCR，ASR 后按字幕行数生成默认图片 PDF |

- 项目名称示例 `The Very Hungry Caterpillar`。
- SRT 输入校验：空文件、超过 **5MB**、编码识别；可载入/下载示例；显示解析条数和末句时间。
- 模型选择分本地 Whisper 与云端。本地离线免费；云端显示预估积分和不足提示。UI 文案约 3 分钟 1 毛钱，仅为构建中的说明，实际价格不应硬编码。
- ydl 下载码可能携带登录上下文；报告不包含任何真实 Cookie。插件可下载，提供 Chrome/Edge 开发者模式安装指引。
- 创建后可后台继续处理；处理队列文案明确同时最多 **3 个项目**，其他显示排队位置。J@1895870 附近。
- 普通项目处理阶段：解析文档、转换音频、生成字幕。状态包括 pending / processing / completed / failed / skipped。
- 视频/仅音频完成时每条字幕映射一页；PDF+audio 通过文本匹配生成行到页的 mappings；PDF-only 将书页文字拆为字幕并跳过转换音频/生成字幕阶段。J@4178000–4183000。

## 8. 绘本排版实验室（动画项目的“绘本”入口）

证据 J@3116300–3434200。该模块为较完整的重排版编辑器，应与绘本源工作台区分。

### 8.1 默认配置

直接来自 J@3132020 的 `ko={...}`，不是视觉估计：

```json
{"paperSize":"A4","orientation":"portrait","columnCount":2,"imageMode":"byColumn","imageCount":1,"comicMinBubbleWidth":"compact","maxPlaceholderHeight":1,"showPlaceholderLabels":false,"imageCorner":"rounded","hideOriginalSubtitles":false,"showChinese":false,"showSpeaker":false,"fontSize":26,"translationFontSize":16,"fontFamily":"","lineHeight":1,"sentenceGap":-1,"pageNumberStyle":"circle","pageNumberPosition":"center","showSentenceNumbers":false}
```

- 纸张 A4/A5/B5，列数1/2；配图按列/按字幕/漫画版。
- 按列在每列顶部固定 N 张；按字幕每 N 句首句插图，随句换列/换页；漫画版含气泡宽度和位置。
- 说话人聚类默认阈值 **0.6**，segmentationStep **0.2 秒**，可修改并重新识别。
