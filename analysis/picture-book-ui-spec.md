## 2. 工作台与项目卡

### 2.1 工作台结构

工作台混合展示文件夹、原创绘本元数据、上传绘本 `bookProjects`。复刻时需在数据模型上区分，不能把它们当作一种卡片。搜索项目时匹配标题；原创绘本搜索还会匹配描述、风格。存在当前文件夹与全局搜索上下文，切换文件夹或搜索条件会清除选中项、菜单状态，滚动位置另有保留逻辑。

默认排序状态名为 `createdAt`、降序，但实际项目比较使用 `updatedAt ?? createdAt`；因此编辑过的老项目可能前移。日期在卡片上仍显示创建日期 `yyyy.MM.dd`。

工作台支持文件夹、选择/批量操作、导入 `.nexusbookpkg`、已完成上传项目的工程导出。具体工程数据契约见同目录 `data-contracts.md`。本文件不把工程包导出与收费点读包导出混为一个功能。

### 2.2 上传项目卡

静态入口：J@3911000–3920700，属于 `cQ`。

- 外框白底、24px 圆角；深褐色 `#3a352f` 约 25% 透明边框，悬浮约 60%；选中为 indigo-600 边框、2px indigo-100 外环及 2px offset。
- 封面宽高比 16:10；无封面时 emerald-50 → teal-50 渐变。封面悬浮放大 1.1，动画 500ms。
- 右上多选框 24×24px、8px 圆角，距上/右 16px；未悬浮且未选中时隐藏。
- 左上未完成状态为“制作中”或“失败”；左下为日期。
- 完成的多音频/自动配音卡右下为绿色模式徽标；单音频显示云端/本地识别模型徽标。
- 标题区左右内边距 20px，标题 12px 粗体，带 `uppercase` 类；“原创”小标 8px。
- 处理中的底部渐变层显示阶段与进度，进度条高 4px、变化动画 500ms。四阶段 completed/skipped 按 100%，其余取 progress，再平均。
- 失败时底部红色渐变显示 `processingError`。TTS 待确认时有读书图标、“待校对识别结果”“点开确认后开始配音”。

## 3. 三种铺码创建表单

### 3.1 共用容器与状态

`WWe` 是居中模态框：固定全屏遮罩，z-index 100，黑色 40%，外层 padding 16px；内容宽度最大 448px、白底、16px 圆角、重阴影。进入动画由 opacity 0、y=20px、scale=.97 过渡到正常。标题区左右 20px、上 16px、下 12px，底部分隔线 slate-100；内容区左右 20px、上下 14px，组间约 14px；底部按钮区同样左右 20px/上下 14px。

标题栏可用 pointer capture 拖动，点按钮或 busy 时不开始拖动。创建期间禁止遮罩关闭和关闭按钮。关闭时拖动位置复位；**表单清空函数明确在成功后调用，单纯取消没有同样的全字段重置调用**，因此“取消后重开保留内容”需按运行再确认，不能自行认定每次重开都清空。

初始值：标题空、书源空、单音频空、多音频空数组、模式 `single`、TTS 声线 `Bella`、语速 `1`、busy=false、error=null、图片转换进度空。

### 3.2 第 01 组：铺码模式

三个等权分段按钮，值和可见文案如下。

| 值 | 名称 | 解释 |
|---|---|---|
| `single` | 单音频铺码 | 一书一音 · 自动识别句子级时间戳 |
| `multi` | 多音频铺码 | 一码一音 · 上传多段音频，创建后在辅码页面手动铺码 · 无需识别文字 |
| `tts` | 无音频铺码 | 一句一码 · OCR 文本由本地 KittenTTS 自动配音 · 离线免费 |

**当前创建界面的多音频是手工铺码模式。** 底层仍保留 `multiAudioAlign=filename/asr` 的兼容分支，但本表单不传它，不能因此增加“文件名匹配”“自动 ASR 匹配”两个 UI 模式。

### 3.3 第 02 组：项目信息

| 字段 | 默认值 / 占位 | 必填与校验 | 交互 |
|---|---|---|---|
| 项目名称 | 空；选书后以文件名去扩展名作占位，否则“选择书籍后自动填写” | 可空；提交时 trim，空值用源文件名干 | 不强制用户输入 |
| 书籍文件 | “书籍文件（PDF / 图片）” | 必选；PDF 或 jpg/jpeg/png/webp/bmp/gif/tif/tiff | 优先走桌面 `selectBookSource()` |
| 图片合成进度 | 无 | 转换期间不能创建 | 完成显示“N 张图片 → 已按文件名顺序合成 PDF（每张一页）” |

EPUB 明确报错：“已不再支持 EPUB，请使用 PDF 或图片作为书籍源”。书源选择器可能返回 PDF、图片组以及同目录音频；选择 PDF 时若尚未手动选单音频，允许自动附带该音频。

图片输入流程：使用数字自然排序、大小写不敏感；先铺白底并压成 JPEG，最长边最多 1800px、质量 .88；每张独立 PDF 页，页尺寸按图片像素×.5 point。存入工程统一叫 `book.pdf`。名称可来自文件夹或首张自然排序图片名，去掉末尾数字/空格/下划线/短横线后推断，兜底“图片绘本”。

### 3.4 第 03 组：按模式变化

| 模式 | 字段 | 默认 / 规则 | 说明与异常 |
|---|---|---|---|
| 单音频 | 整书音频 | 必填；`audio/*`；单文件 | 保存名 `book-audio.<小写扩展名>`，无扩展名兜底 mp3 |
| 单音频 | 当前识别模型 | 打开时读 `cx().currentModel` | 展示模型名称、大小/描述；改模型会关闭弹窗并打开设置的模型页 |
| 单音频 | 云端费用预估 | 读音频时长与 `subtitle_generation` 价格配置 | 前端兜底 20 积分/60 秒；云端可覆盖，不应固化为真实服务器当前价格 |
| 多音频 | 音频文件 | 必填至少 1 个；`audio/*`；multiple | 多次选择追加；未见去重与逐项移除，只有“清空”全部 |
| 多音频 | 文件摘要 | 展示前 3 个名称，再“等 N 个” | “每个文件对应一个码点，如每页/每句一段 mp3” |
| 无音频 | 声线 | `Bella` | 女声 Bella/Luna/Rosie/Kiki；男声 Jasper/Bruno/Hugo/Leo |
| 无音频 | 语速 | `1`；.5–1.5；step=.1 | 展示一位小数和 x；本地 KittenTTS、英文 OCR 句子、离线免费文案 |

单音频模型区：云端有“云端模型”“高级”“句子级时间戳”及费用估算；本地标“本地模型 · 离线运行 · 免费”。未设置模型显示警示及去设置入口；但最终创建按钮的禁用表达式**不包含“必须已选模型”**，后台助手存在无当前模型时走云端的兜底。复刻时须记录这一差别，不能把警示自然推导为硬阻断。

### 3.5 提交与错误

创建按钮禁用条件：书源不存在；或 single 缺单音频；或 multi 音频数为 0；或 busy；或正在图片合成。标题不参与禁用。处理函数还校验有登录用户、桌面文件 API 可用。错误区域 rose-50 背景/rose-200 边框。成功后回调、关闭、清空表单；失败保留输入以便修正。

## 4. 制作状态机、持久化与恢复

### 4.1 数据骨架

`u3` 先保存源书和音频文件，再写 `NexusDB.bookProjects`：`id/title/userId/folderId/sourceType/sourceFileName/audioFileName/audioMode/audioFiles/multiAudioAlign?/ttsVoice?/ttsSpeed?/status/processingSteps/currentStepIndex/createdAt/updatedAt`。`sourceType` 固定 `pdf`、`sourceFileName` 固定 `book.pdf`；时间为毫秒 epoch。多音频列表区分内部 `fileName` 与用户看到的 `originalName`。初始 status=`processing`、currentStepIndex=0。

阶段顺序固定：`ocr → audio_conversion → transcription → alignment`。skipped 的 progress=100，不能把 skipped 画成错误。

| 模式 | OCR/页面准备 | 音频转换 | 语音识别 | 对齐/配音 |
|---|---|---|---|---|
| single | pending → 完整 OCR | pending → audio.wav | pending → ASR | pending → OCR 与字幕对齐 |
| multi（现有表单） | pending → 页面准备，句子/块为空 | skipped | skipped | skipped；完成后手动绑定 |
| tts | pending → 完整 OCR | skipped | skipped | pending；等待校稿确认后合成 |

多音频的第一阶段沿用 `ocr` 的阶段键，但当前默认分支实际只准备页尺寸、封面等元数据，不识别文字。不能仅根据阶段名字宣称多音频经过 OCR。

### 4.2 TTS 的等待点

TTS OCR 完成后：status 仍 `processing`、currentStepIndex=3、`ocrConfirmed` 尚未为 true。卡片通过“tts + !ocrConfirmed + processing + OCR completed”派生待校对外观。用户确认 OCR 后 `ocrConfirmed=true` 才进入生成，不能自动跳过校对。

按保留的非空、有框句子顺序调用本地合成，写 `tts-0001.wav` 等与 `book-audio-mapping.json`。单句失败可跳过，全部失败则任务失败。完成记录映射音频数和时长。无文字、无可用框的条目不应生成点读音频。

### 4.3 成功、失败、重试

轮询间隔 3000ms，每轮最多处理 2 个项目任务，活动集合防重复。成功置 completed；失败置 failed、活动阶段 failed，并写 `processingError`。

- 全量重试 `xF`：重置阶段、processing、currentStepIndex=0，清错误与任务状态。
- 重新对齐 `hse`：前三阶段没有完成时退到全量重试；否则只将 alignment 置 pending。
- 校稿确认 `aSe`：更新句数、ocrConfirmed=true、processing、currentStepIndex=3。
- 按校稿重新配音 `fse`：alignment pending、processing、ocrConfirmed=true。
- 应用裁剪 `oSe`：替换源 PDF；重新 OCR 和 alignment；保留已经完成的音频转换/识别，符合条件时保留 subtitleTaskId。

主要工程文件包括 `book.pdf`、`book-cover.jpg`、`audio.wav`、`subtitles.lrc`、`book-ocr.json`、`book-ocr-reviewed.json`、`book-alignment.json`、`book-audio-mapping.json`、`book-page-mapping.json`、`book-line-ocr-mapping.json`、`book-custom-codes.json`、`book-custom-audio.json`。

## 5. 解析详情弹窗

`jqe`：固定遮罩 z100、黑色 50%，居中 padding16；弹窗宽 96vw、最大 1700px，高 93vh，白底/16px 圆角。顶部 px24/py16，标题 15px，副标题显示源类型、页数、文字块数、对齐句数/词级信息。单音频有“重新对齐”，另有关闭。

正文左侧 flex PDF 预览，右侧固定 400px 列表；可隐藏右列表进入 PDF 全视图。PDF 图片 object-contain，在 OCR 原始尺寸对应的 SVG 坐标中叠加框，不应拿缩略图像素直接保存标注。

- 底部翻页、显示/隐藏全部文字框、全视图/列表切换。
- single 默认字幕页签；multi/tts 默认文字块页签，且不展示单音频的字幕页签。
- 字幕条点击定位对应 PDF 页与框，播放按钮试听；页码 Pn 标签可区分精确/启发式映射，无匹配显示“无对应”。
- 列表选中 indigo，播放 amber；页面框按选择来源使用 rose/amber/indigo，全部框为 sky。
- 文字块按版面区域/region 分组，显示文本与音频对应信息；未匹配项有“未匹配”徽标，TTS 的匹配项显示“配音”。
- 读取 OCR、字幕、对齐、页映射、行 OCR 映射等结果；每 2500ms 刷新对齐及映射文件。

当前无成功项目运行截图；长列表虚拟化/滚动细节、PDF 极端横纵比的留白应列为后续截图验收项。

## 6. OCR 校对与源书裁剪

### 6.1 OCR 校对

`Eqe` 全屏 fixed z50，背景 `#f5f6f8`。白色顶部 px16/py12、底边 `#e8e4dc`，显示“OCR 校对 · 项目名”、页数/句数，以及手工句、无框句、空手工句等统计。

正文 padding12/gap12，左右各半；白底、12px 圆角、slate-200 边框。左侧整书 PDF 页纵向展示，右侧按页分组句子列表，页标题 sticky。选择句子时双向定位滚动。普通 OCR 框绿色 `#10b981`、约 .10 填充；手工框蓝色 `#0284c7`、虚线、约 .14 填充；活动框红色 3px 加阴影。

识别参数弹出面板宽 288px：box score threshold 默认 .45，范围 .30–.60，step=.01；可指定单页重新识别，页码初值为 1 或当前页；整书 OCR 并发 3。整书识别逐页写入界面，取消时已经完成的页保留新结果、尚未处理的页保留旧结果，过程中锁定编辑。

编辑操作：

| 操作 | 静态行为 |
|---|---|
| 补一句 | 当前页插入手工句；默认框宽约页宽 76%，高 max(页高5%,12 OCR px)，位于页中约45%高度 |
| 画框补字 | 页内拖出框；小于页宽1.5%或页高.8%的拖动不创建 |
| 移动/缩放手工框 | 限制于页面内部；最小 8×6 OCR px |
| 句子编辑 | 13px 自动高度 textarea；焦点/选中行浅红 |
| 合并上一句 | 仅同页可合并 |
| 在光标处分句 | 按 textarea caret 拆分 |
| 下方插入空句 | 用于手工补文字 |
| 删除 | 删除句子；删除 OCR 框也删除其句子 |
| 恢复原始识别结果 | 删除 reviewed 覆盖并回到原始 OCR |

OCR 原始结果是 `book-ocr.json`，校稿覆盖单独保存 `book-ocr-reviewed.json`；读取优先 reviewed、失败或不存在再读原始。定位 J@750252、唯一词 `s8="book-ocr-reviewed.json"`；`c0e` 专读原始、`FP` 写 reviewed、`d0e` 删除 reviewed。它不是“备份一份原始文件后覆盖同名源文件”的实现。

底部显示当前页/所选文本摘要；“稍后再说”只关闭、不确认保存；“确认并开始配音”在忙、无非空句、整书识别中禁用。至少保留一条句子，否则提示“至少要保留一条句子才能配音”。确认保存校稿；原本 completed 则重新配音，否则标为 OCR 已确认，随后关闭。

### 6.2 源书裁剪

`Cqe` 全屏 fixed z210、白底，顶栏 px16/py12、rose 主色；显示当前页数→输出页数及删除段数。默认工具 `h` 横线，可切竖线；点页上任意位置添加线，或拖动工具到页面。线位置钳在页面 2%–98%，应用时近线归一化需保持约1%间距。

每页容器最大 860px，纵向间隔16px、横向留白24px。`Lce` 中线为 rose-500 的2px线，配圆形拖把及24px删除按钮；拖动结束排序。页面可横竖交叉切分。每段有“删除此段/恢复此段”；无切分线时可“删除本页”，初始悬浮才出现。删除段显示玫红斜条纹。无切分线时底部有“添加横/竖切分线”在正中加一条。

输出顺序为先行后列：从上到下，每行从左到右；保留源 PDF 90°倍数旋转。删除线/移动线后会按旧删除区域与新区块面积重叠至少50%来迁移删除状态，不只是沿用旧段下标。

应用按钮在 busy、未编辑、项目 processing 时禁用。确认框 z220、最大384px，列出原页数→输出页数、切分线/删除数，明确提醒直接替换原始 PDF、不保留删除片段、历史切分线清空。确认调用 `oSe` 触发重新 OCR/对齐；不是单纯前端预览裁切。Esc 非应用中可返回。此处尚未实际覆盖测试样书。

## 7. 原书辅码编辑器

### 7.1 页面布局与持久化

`lHe` 全屏 fixed z210、白底；顶栏 px16/py12、边框 `#e8e4dc`。依次为返回（Esc）、32px 图标、标题“辅码”/项目名、模式/模型徽标、辅码开关、导出点读包。

正文三栏：左设置默认展开宽240px，可收起为40px，背景 `#faf9f6`；中间 flex、slate-100 底、纵向滚动 PDF 页面，最大页宽860px；右侧仅 single 显示识别文字，默认展开宽224px，可收起为40px。multi/tts 不显示此右栏。

**当前原书编辑器调用音轨组件时传 `docked:true`：音轨面板停靠于主预览底部，宽度充满主栏，选中有效框后出现，可折叠。** 同组件另有浮动、拖拽、默认宽380px的分支，但不是当前 `lHe` 的默认布局，不能据此复刻一个悬浮窗。

设置 localStorage key 为 `auxCode:<projectId>`，修改经 `xN` 归一化后持久化。手工框与自定义音频保存在工程文件；音轨校准、排除、重复次数、框位置覆盖保存在 alignment 元数据。左下“恢复默认”仅把设置对象恢复 `Ya`，不等于删除手工区域或音频绑定。

### 7.4 区域、手工铺码与音频资源

自动区域依据粒度生成：page整页；paragraph按字间距/行距聚合，遇插图/空白/分栏断开，不依赖版面type标签；sentence一句的多段文字框共用码值，预览为黄色句框。可关闭/标准/宽松合并相邻OCR块，调整点读面积仍避免区域相互覆盖。

手工绘制进入专用模式，页面顶端粘性提示条；按住拖出矩形/圆，松开完成后自动退出，Esc取消。默认形状物理尺寸：矩形30×22mm、圆26×26mm。手工框可移动/缩放，列表显示页码、形状、尺寸、绑定音频，可选中定位、删除。清空所有手工框会逐项清除其校准及自定义音频绑定。

multi 音频资源按 originalName 数字自然排序。点击资源选中并试听，再次点击取消；可把资源拖到 PDF，也可选音频后在页内画框绑定。资源徽标展示已放置页码，超过3项显示前3项加数量。一个资源可在多个区域复用。

自定义语音接受 `audio/*`，文件上限50MB；“更换音源”后整段播放，优先级高于自动音轨区间。“移除”恢复朗读原音与可微调区间。手工框数据文件 `book-custom-codes.json`、音源映射 `book-custom-audio.json`；更改应保存，不仅更新内存。

### 7.5 音轨微调与识别文字

选中区域后出现底部音轨面板：开始、结束、复制、粘贴、不赋码/已跳过、作为入口码、遍数、试听、更换音源、移除或重置。

- 开始/结束展示3位小数；number step=.01、min=0，失焦或Enter提交。区间限制音频时长内，边界微调常量 .02秒；波形视窗最小 .4秒。不能把最小视窗 .4秒误当成导出最短音频（导出过滤阈值是 .005秒）。
- 波形支持点选播放、手柄调起止、缩放、聚焦当前选择、背景平移。波形取音频第一声道，压为1000个峰值采样。
- 复制/粘贴是应用内部区间剪贴板；Ctrl+C/V（Mac为⌘），文本输入焦点时不拦截。粘贴到另一框后保存并提示。不是复制实际音频文件到系统剪贴板。
- 不赋码后区域显示灰色虚线并被导出跳过；可恢复。
- 作为入口码后该框不再占内容码，音频导出为cover.mp3，常规贴纸入口取消；再次切换可恢复。
- 遍数默认1，**实际1–9**，输入、保存、读取均由 `Zk=9` 钳制。该构建另有 `ZA=12` 常量，不是本输入范围。导出为同一区间重复N遍拼成一条，试听也连播。
- 重置仅清手动校准、退到自动区间。

single 右侧“识别文字”宽224px，按识别行分组、显示该行首词时间及总词数，选中框时自动滚到相关词。可点词重新选择范围，并清空当前选择；禁用状态与无数据空态各有表现。multi/tts 不显示该面板。

## 8. 点读包导出

### 8.1 可用条件与反馈

导出总条件：辅码开关开启、OCR/页面数据存在、生成页计划不为空；single 还需字幕音轨就绪；multi/tts 至少有已映射音频，或至少一个手工区域绑定了有效音源。当前 multi 即使没自动映射，手动放置并绑定后也可正常导出。

没有页数时“无法获取项目页数”；首批 PDF 正在渲染、剩余页渲染、渲染失败分别有状态。码值超出资源上限时提示具体页码与dpi上限。错误有顶部/导出按钮下方红色可关闭提示；普通复制/粘贴保存提示位于顶部中央，成功绿色、提示/错误琥珀色，约2.2秒消失。

点导出先出现确认框：z230、最大384px、白底16px圆角；显示200积分单次费用、当前余额、导出后余额，不足时红色提示且确认禁用。余额尚未获取显示加载提示，静态按钮禁用逻辑并不等待余额数值。确认导出后 z220 半透明遮罩+模糊背景、288px白卡，显示进度文案与百分比。

200是本构建常量 `Zx`，实际服务通过 `authorize-book-oid-export` 授权，不代表已经实测收费成功。定位 J@2094167。未登录错误明确为“请先登录后再导出点读包”。

### 8.2 保存顺序与产物

静态调用顺序：生成计划/读取源书 → 调用桌面 `bookOidBundlePickPath` 选择保存位置 → 用户取消则直接返回 cancelled → 生成码点层/合成PDF/生成音频ZIP/上传暂存 → 调用授权服务 → 桌面 `exportBookOidBundle` → finally清理暂存文件。确认弹窗文案“若之后取消另存为则不扣费”，与选路径在授权前的前端顺序相符；服务器扣费原子性、写盘失败退款等仍未验证。

- 图码一体：一个内容PDF，码点叠印；图码分离：内容PDF+码点层PDF，两份可选装订页码。
- 不去黑路径尽量保留PDF内容；去黑路径涉及光栅化内容处理，不能承诺矢量100%保真。
- 码点生成调用 `labOidOverlayRegions` 桌面能力，虽API名含lab，但当前入口是原书辅码，不是动画实验室页面。
- ZIP名包括书名、dpi、点阵尺寸、时间戳。
- 音频含入口 `cover.mp3`（生成成功或选定入口框时）与内容 `1/<码值>.mp3`。
- 默认入口音频可由书名TTS生成；中文书名则采用入口编号文本，失败警告并允许跳过cover。
- readme列书名、入口码、内容码范围、音频数、粒度、图码模式、纸张缩放、dpi/点阵及文件列表。
- 内容音频按音源文件/文件列表或精确至3位小数的时间区间签名复用，重复遍数参与时间片签名；仅大于5ms的区间进入有效集合。
- 没有可导出音频、码值不足、页数不匹配、音频未就绪等会报错，不应导出一个表面成功但缺音频的包。

## 9. 已知不一致、未知项与验收清单

### 9.1 必须保留的静态事实

1. 默认模式single，书源PDF/图片，EPUB已经移除。
2. 当前multi是手动一码一音；任务键ocr不代表跑了文字识别；不能放出兼容分支中的旧模式按钮。
3. TTS待校稿仍为processing，卡片展示专用等待态；确认前禁止提前生成。
4. 卡片主体完成后进阅读器；解析详情在更多菜单。
5. 原书辅码左240/中flex/右224；右栏仅single；音轨停靠底部。
6. 点阵初始化2×2，帮助文案3×3“默认”矛盾；遍数实际1–9。
7. 校稿单独存reviewed文件；恢复原始不是重新OCR。
8. 裁剪替换源PDF并重跑OCR/对齐，保留既有ASR成果，不是纯视图裁剪。
9. cloud ASR价格配置可变；点读包200积分是静态前端展示值，授权仍由服务裁决。
